# L'entraide du campus

Une appli où chaque étudiant propose ce qu'il sait faire et cherche ce dont il a besoin. Projet du module Vibe Coding (M2 Data).

La fiche d'identité du projet est dans [`CLAUDE.md`](CLAUDE.md).

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
